# Push this project to GitHub (2 minutes)

This folder is **already a git repo**: everything is committed, the remote is set to
`https://github.com/Waleed-Azam/Astro-Developer-.git`, and history is merged.
You only need to authenticate + push.

## Option A — Terminal (macOS / Linux / Windows Git Bash)

1. Unzip this file and open a terminal **inside** the `Astro-Developer-` folder.
2. Run:
   ```
   git push origin main
   ```
3. When asked to log in:
   - Username: `Waleed-Azam`
   - Password: a **Personal Access Token** (NOT your GitHub password).
     Create one: github.com/settings/tokens?type=beta → this repo only →
     permission **Contents: Read and write**.

## Option B — GitHub Desktop (no terminal)

1. Unzip. Open GitHub Desktop → **File → Add local repository** → select the folder.
2. Click **Push origin** (log in if asked).

## Verify

Open https://github.com/Waleed-Azam/Astro-Developer- — the README with pictures + video should render.
Video file: `docs/walkthrough.mp4` (plays right in the browser).
